# Security Policy

## Supported Versions
This is a bootstrap repo and does not ship binaries. Please open an issue for security concerns.

## Reporting a Vulnerability
If you believe there is a security vulnerability, please open a GitHub issue with:
- Description
- Reproduction steps (if applicable)
- Impact assessment

## Important Safety Note
This project will **not** help bypass corporate MDM/Jamf controls or other device management/security mechanisms.
